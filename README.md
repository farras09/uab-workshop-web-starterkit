## 🎯 Target Pembelajaran
1. **HTML5 Semantik:** Memahami pemakaian `<main>`, `<article>`, `<header>`, `<nav>`, dan `<footer>`.
2. **CSS Box Model:** Memahami peran `box-sizing: border-box`, `padding`, `margin`, dan `border`.
3. **Flexbox Layouting:** Memusatkan elemen ke tengah layar (`justify-content`, `align-items`) dan mengatur deretan tombol.
4. **CSS Variables & Modern Styling:** Mengatur palet warna terpusat dan efek transisi hover.
5. **AI as Copilot:** Memvalidasi kode dan menanyakan tips optimasi pada AI dengan prompt terstruktur.

## 📝 Langkah Pengerjaan Peserta (Hands-on Checklist)
- [ ] **Langkah 1:** Buka folder project di VS Code (atau teks editor favorit Anda).
- [ ] **Langkah 2:** Buka file `index.html` via ekstensi *Live Server* atau double-click buka di browser.
- [ ] **Langkah 3:** Edit `TODO 1` sampai `TODO 4` pada `index.html` (Ganti foto, nama, bio, dan link media sosial Anda).
- [ ] **Langkah 4:** Buka `css/style.css`, perhatikan bagian `:root` dan coba ubah nilai `--accent-primary` dengan warna kesukaan Anda.
- [ ] **Langkah 5 (Eksperimen Flexbox):** Coba matikan baris `display: flex;` pada `body` di CSS untuk melihat perbedaannya saat elemen tidak dipusatkan!

## 🤖 AI Prompting Sandbox (Latihan Berkolaborasi dengan AI)
Gunakan AI (ChatGPT, Claude, atau Gemini) sebagai **rekan code-review**, bukan untuk copas membabi buta!

### Contoh Prompt Review (Sangat Direkomendasikan):
> *"Saya sedang belajar CSS Flexbox untuk membuat bio link card sederhana. Berikut potongan kode CSS saya: [paste kode .profile-card]. Apakah struktur Box Model dan Flexbox saya sudah rapi dan responsif di mobile? Berikan masukan perbaikan tanpa mengganti seluruh kodenya."*

### Contoh Prompt Penjelasan Konsep:
> *"Jelaskan dengan analogi sederhana mengapa 'box-sizing: border-box' sangat penting digunakan di awal file CSS?"*
